# 🏥 Healthcare System Performance & Patient Outcome Dashboard

## 📊 Project Overview
This project features a production-grade, executive-level dashboard built in **Microsoft Excel** to monitor, analyze, and visualize patient outcomes, length of stay (ALOS), medical condition distributions, and insurance payer mixes. It utilizes a dataset of 1,000 patient records to bridge clinical operations with executive decision-making.

---

## 🚀 Key Features & Technical Workflow
* **Data Cleaning & Governance:** Addressed boundary anomalies in age and length of stay, standardized text attributes, and verified data integrity.
* **Calculated Metrics Layer:** Developed robust formulas (`COUNTIF`, `AVERAGE`, `COUNTA`) combined with percentage transformations for dynamic KPIs.
* **Advanced Visualizations:** Designed clustered bar charts, doughnut distributions, and stacked payer breakdowns.
* **Interactive Filtering:** Connected multi-dimensional slicers (**Admission Type**, **Region**, and **Insurance Type**) for seamless cross-filtering across all charts.

---

## 📌 Core KPIs
* **Total Patients:** 1,000
* **Average Length of Stay (ALOS):** 10.04 Days
* **Average Patient Age:** 45.7 Years
* **Treatment Success Rate:** 36.3%
